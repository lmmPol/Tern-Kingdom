# Терновое Королевство — Модульная сборка (Акт III)

## Структура проекта
- `index.html` — точка входа и разметка интерфейса
- `css/main.css` — базовые стили, сцена, карточки персонажей и тосты
- `css/adventure.css` — стили экрана приключений и глав
- `data/heroes.js` — данные всех 6 персонажей и главы приключений
- `js/app.js` — основная логика сцены, карточек и переходов по главам
- `js/audio.js` — процедурный звук костра (Web Audio API)
- `assets/bg.png` (и `assets/bg.jpg`) — фоновая иллюстрация лагеря
